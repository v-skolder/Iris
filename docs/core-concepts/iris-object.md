# Iris Object

`Iris()` configures and registers dashboards. The example sets `html_base_directory`, registers `example_dashboard` with `add_dashboard(...)`, associates a `DashboardDataSource` with a Cube and a PayloadFormatter, specifies the HTML file, and calls `run()`. See [app.py](../../project-example/src/app.py).

The dashboard's `publish` operation produces [published artifacts](publish-artifact.md).
